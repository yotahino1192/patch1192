# Patch 共通カラーパレット

2026-09-17 のユーザー指定を、今後の全画面（Home、Patches、教材追加、Progress、Lesson、認証、設定、モバイル）のカラー基準とする。実装の正本は `app/palette.css`。新規・修正UIではこのトークンを再利用し、独自のブランド色を増やさない。

| 色 | HEX | 用途 |
| --- | --- | --- |
| Evergreen | #12564F | ブランド、本文・見出し、現在のレッスン、白背景の主要アクション |
| Mint | #D6F3E5 | 補助サーフェス、学習履歴、選択背景 |
| Peach | #FFDCB5 | Evergreen上の開始ボタン |
| Leaf green | #28845B | 達成表示、通常のストリーク |
| Orange | #FF9600 | サーバーがhotと判定したストリークと炎 |
| Blue-gray | #A9BBC5 | 非アクティブ状態、補助的な線・装飾 |
| White | #FFFFFF | 主背景、濃い背景上の文字・アイコン |

## 適用ルール

- 画像の「Previous streak after a gap」より、直前のユーザー指定を優先する。連続学習が途切れても、過去の達成チェックはLeaf greenを維持する。
- Streakの達成条件、日付、hot/broken/stale判定、Retentionの意味は変更しない。日数からUIで独自判定しない。
- Blue-grayは白地の小さい文字には使用しない。本文や補助文字には読みやすい濃さを維持し、必要な場合のみこのパレットから濃淡を派生させる。
- エラー・削除・警告など既存の意味を持つ色、キャラクター素材、互換性が必要なダーク表示は、ブランド統一だけを理由に機械的に置換しない。
- 既存画面には直書きの派生色が残る。今後その画面を変更する際に共通トークンへ揃える。今回の変更で全セレクタ・全素材の配色変更が完了したとは扱わない。
